# 物资招标

## 潜污泵

需明确参数：

1. 流量、扬程、功率。
2. 带液位自动控制装置
3. 是否带高液位报警，一般不需要。
4. 是否带 BA 控制，一般不带，看设计。
5. 控制箱防水等级，有水的机房，一般 IP55
6. 控制箱是否自带双电源切换模块，一般不需要，如果是消防、电梯井的潜污泵，一般设计有双电源，但一般在上端电源箱设置有双电源切换，所以潜污泵控制箱一般不需要带双电源切换模块。

## 组合式空调机组

空调机组招标澄清：
要求：
1、图纸参数中变频的，选型也要变频；
2、控制箱内元器件需要满足指定品牌；
3、循环水湿膜加湿材料采用普通的材料；
4、箱板、内板、挡水板等采用普通镀锌钢板材质；
5、箱板厚度采用普通厚度；
界面：
1、包含 PLC 控制柜、传感器（温度、湿度、压差等），**包含风阀，不包含水阀**。（组空需要控制电动风阀，组空厂家提供的质量更好，因此包含更好）
2、包含 PLC 控制柜的弱电接线施工（包含与传感器、风阀、水阀的控制、反馈接线），不包含强电接线。

选型：

组空外板厚度：50mm，外壁板采用厚度不小于 1.0mm 的彩钢板，内壁板采用厚度不小于 0.8mm 的不锈钢板制作

中效过滤：静电除尘（更改为袋式 F7，造价更低）

风机：变频（改为定频风机（2 级能效），无变频器，风机三档调速，造价更低）

风机：一级能效（改为 2 级能效，造价更低）

湿膜加湿：有机湿膜（最普通的）

## 水泵

联轴器：使用联轴器的话，方便检修，没有也不影响使用，本项目招标不使用联轴器。
