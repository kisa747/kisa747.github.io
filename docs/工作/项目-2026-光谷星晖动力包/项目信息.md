# 项目信息

项目名称：光谷星晖智能产业化基地一期项目工程总承包（EPC）之公用动力包
招标人：信息产业电子第十一设计研究院科技工程股份有限公司
招标代理机构：湖北省成套招标股份有限公司

建设规模：本项目为光谷星晖智能产业化基地一期项目，一期用地面积约205 亩，总建筑面积约24 万平方米，主要包含7台冷水机组（4 台低温冰机、3 台热回收冰机，共计18300TR）、4 台冷却塔，3 台锅炉共计10.5MW,及其附属设备及管道系统的施工及调试等工作。

建设地点：武汉市东湖新技术开发区九龙湖街以北、苏湖路以西

招标内容及范围：本包为光谷星晖智能产业化基地一期项目提供完整的冷热水系统。包括冷却水系统、冷冻水系统、热水系统、热回收水系统、天然气系统、冰机系统图纸深化设计、设备采购、管道安装等工作。

计划工期：计划总工期 448 天（不包含开始日期）
