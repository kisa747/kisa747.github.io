## 能效等级

根据《GB 19577-2024 热泵和冷水机组能效限定值及能效等级》，一般常见的冷水机组归类为蒸气压缩循环冷水（热泵）机组。

在**综合部分负荷性能系数（IPLV）** 和**性能系数（COPc）** 这两个指标体系中，**任选其一**达到1级要求即可，无需同时满足。

蒸气压缩循环冷水(热泵)机组的能效等级指标采用双通道评价指标，选取综合部分负荷性能系数(**IPLV**)(见表1)或性能系数(**COPc**)(见表2)中的一个指标体系的能效值进行能效等级判定。

蒸气压缩循环冷水(热)机组 water chilling(heat pump)packages using the vapor compression cycle

采用电动机驱动的蒸气压缩制冷循环，将低温流体侧(水或空气等)中的热量转移到高温流体侧(水或空气等)用以冷却液体(或另具加热液体功能)的机组。

性能系数 COP（coefficient of performance）

在规定的标准工况下或机组特定的使用工况下，以相同单位表示的制冷(热)量与机组总消耗功率的比值。

[来源:JB/T7249-2022，2.55,有修改]

注1：单位为千瓦每千瓦(kW/kW),且保留2位小数(作为过程参数时至少保留3位小数)。

注2：制冷、制热、蓄冷制冷性能系数分别用COPc、COPh 和 COPcs 来表示。

综合部分负荷性能系数  IPLV（integrated part load value）

基于规定的标准工况下机组部分负荷的性能系数，按机组在特定负荷率下运行时间的加权因数，通过计算获得的一个单一数值表示的机组部分负荷效率指标。

来源:JB/T7249-2022，2.57,有修改]注1:计算见公式(1)。

IPLV(或 NPLV) =2.3% X COPe100% +41.5% X COPe75% +46.1% X COP 50% +10.1% XCOPe25%

式中:

COPc100% 、COPe75% 、COPe50% 和COPc25%分别为100%、75%、50%和25%负荷率下的制冷性能系数。

注2:测试时，部分负荷百分数的计算基准是名义制冷量的明示值，100%负荷指制冷量调节至名义工况下机组的满负荷制冷量。

注3:综合部分负荷性能系数表征了平均的单台机组的运行情况，不代表某一特有的工程安装实例。

注4:单位为千瓦每千瓦(kW/kW)，且保留2位小数。
