# 工业管道等级与监督

工业管道属于特种设备，其等级划分、监督检验、定期检验均依据以下现行规范与标准确定与实施[^1][^2][^3]。

## 相关规范

| 标准 | 名称 | 性质 | 实施日期 | 定位 |
| ---- | ---- | ---- | -------- | ---- |
| TSG 31-2025 | 工业管道安全技术规程 | 强制性安全技术规范 | 2026-01-01 | 分级规则 + 设计、制造、安装、使用、检验全生命周期基本安全要求 |
| GB/T 20801.1-2025 | 压力管道规范 第 1 部分：工业管道 | 推荐性国家标准 | 2026-05-01 | 技术实施细节，合并原 GB/T 20801.1~6-2020 六部分为一部 |
| TSG D7006-2020 | 压力管道监督检验规则 | 强制性安全技术规范 | 2020-09-01 | 制造监检与施工（安装、改造、重大修理）监检要求 |

说明：

* TSG 31-2025 整合修订了《压力管道安全技术监察规程—工业管道》（TSG D0001—2009）、《压力管道定期检验规则—工业管道》（TSG D7005—2018），后两者作废[^1]。
* 介质毒性、易燃性等危害判定（级别划分层面）统一依据 GB/T 42594-2023《承压设备介质危害分类导则》[^4]，不再采用《危险化学品目录》、GB 50160、GB 50016 作为判定依据。注：2019 年第 3 号公告《特种设备生产单位许可目录》中 GC1 定义仍引用《危险化学品目录》、GB 50160、GB 50016，行政许可层面尚未同步更新[^5]。
* 管道级别划分：TSG 31-2025 划分为 GC1、GC2、GCD 三级[^1]；GB/T 20801.1-2025 划分为 GC1、GC2、GC3 级（GCD 动力管道不在其适用范围内，见其 1.4 g）[^2]。两者在 GC1/GC2 划分规则上保持一致。

## 特种设备适用范围

[质检总局关于修订《特种设备目录》的公告，2014 年第 114 号](https://www.samr.gov.cn/tzsbj/tzgg/zjwh/art/2014/art_075b6c60ca144be7a425e80f20c17af3.html) 文的《特种设备目录》定义范围内、同时具备以下条件的工业管道[^6]：

1. 最高工作压力大于或者等于 0.1 MPa（表压，下同），并且不大于 100 MPa[^1]（注：100 MPa 上限来自 TSG 31-2025 1.2(1)，特种设备目录本身无此上限）；
2. 公称直径大于或者等于 **50 mm**；
3. 输送介质为气体、液化气体、蒸汽，或者可燃（易燃）、易爆、有毒、有腐蚀性、最高工作温度高于或者等于标准沸点的液体。

**不适用的范围：**

1.4.5 公称直径小于 150mm，并且其最高工作压力小于 1.6MPa（表压）的输送无毒、不可燃、无腐蚀性气体（不包括液化气体、蒸汽和氧气）的管道；

## 压力管道等级划分

按设计压力、设计温度、介质毒性程度、腐蚀性和火灾危险性，划分为 GC1、GC2、GCD 三级[^1]（GB/T 20801.1-2025 另有非监管类 GC3 级，见下表）。

| 级别 | 名称 | 划分条件 | 依据 |
| ---- | ---- | -------- | ---- |
| **GC1** | 高风险（满足任一） | ① **毒性介质**：输送 GB/T 42594 中急性毒性类别 1 介质、急性毒性类别 2 气体介质、工作温度高于标准沸点的急性毒性类别 2 液体介质；<br/>② **易燃介质 + 高压**：输送 GB/T 42594 易燃气体（类别 1/2，含化学不稳定性气体类别 A/B）或易燃液体（类别 1/2），且设计压力 ≥ 4.0 MPa；<br/>③ **高压 / 高温**：输送流体介质，且设计压力 ≥ 10.0 MPa，或设计压力 ≥ 4.0 MPa 且设计温度 ≥ 400 ℃ | TSG 31-2025 附件 A 中 A1.1；GB/T 20801.1-2025 第 4.1 条 a) |
| **GC2** | 中风险 | 除 **GC1 级以外**的工艺管道、界区内公用工程管道及制冷管道，均为 GC2 级 | TSG 31-2025 附件 A 中 A1.2；GB/T 20801.1-2025 第 4.1 条 b) |
| **GCD** | 动力管道（单列） | 火力发电厂用于输送**蒸汽、汽水两相介质**的动力管道，单独划为 GCD 级，不再属于 GC1/GC2 | TSG 31-2025 附件 A 中 A1.3 |
| **GC3** | 非监管类别 | 定义：GB/T 20801.1-2025 仍保留 GC3 级定义，但明确为非监管类别——设计压力 ≤ 1.0 MPa、设计温度高于 -20℃ 且不高于 185℃、输送低危害性液体或者公称直径小于 150 mm 输送低危害性气体的管道；<br/>行政许可：根据 [市场监管总局关于特种设备行政许可有关事项的公告（2019年第3号）](https://www.samr.gov.cn/tzsbj/zcfg/gfxwj/art/2019/art_b02ee8c0fa074ad2a50a97f825790b85.html)，压力管道行政许可级别已取消 GC3 级（许可参数级别仅 GC1、GC2、GCD），此类管道不属于《特种设备目录》监管范围，设计、安装不需行政许可、监督检验和使用登记 | GB/T 20801.1-2025 第 4.2 条；2019 年第 3 号公告附件 1 |

## 不同等级监管要求差异

* **设计**：GC1 级管道以及设计压力 ≥ 16.7 MPa、或者设计压力 ≥ 4.0 MPa 且设计温度 ≥ 570 ℃ 的 GCD 级管道，其材料等级表、应力计算书、设备布置图和管道布置图应当有设计、校核、审核、审定四级签字[^1]。
* **制造与安装**：GC1 级管道（检查等级 Ⅰ）焊接接头实施 **100% 无损检测**（目视、磁粉/渗透、射线/超声均 100%），并强化表面无损检测和硬度检查；GC2 级管道按比例抽检（20%/10%/5%）[^2]。
* **监督检验（TSG D7006-2020）**[^3]：
  * 施工监检：工业管道的安装、改造、重大修理过程，由监督检验机构实施监检；
  * 制造监检：埋弧焊钢管、聚乙烯管以及元件组合装置中的燃气调压装置、减温减压装置、工厂化预制管段、流量计（壳体）。
* **使用登记**：使用单位应按照 TSG 08《特种设备使用管理规则》办理使用登记证[^1][^7]。根据市场监管总局 2025 年第 36 号公告（发布 TSG 31-2025），规程实施前已投用的长输管道系统中输油输气站场内的工艺管道、机场供油管道，应于 **2026 年 12 月 31 日前**办理使用登记，**2026 年 12 月 31 日后未办理使用登记的管道不得使用**；技术资料缺失的，按公告规定处理：使用单位应到制造单位补齐资料；不能补齐的，可提供安装过程中理化检验、管道对接接头 100% 射线或超声检测、耐压试验合格报告代替；仍不能提供的，可委托技术机构开展相应检验检测补齐资料，经定期检验合格后办理使用登记[^8]。

## 定期检验周期与 RBI

**RBI（Risk-Based Inspection，基于风险的检验）**：一种以风险评估为基础的检验策略方法。通过对管道失效可能性与失效后果进行综合分析，确定风险等级与风险可接受程度，据此优化检验的时间、内容和方法，在保障安全的前提下实现检验资源的合理配置、适当延长或缩短检验周期[^1]。

依据 TSG 31-2025 第 7.9 节，采用 RBI 需满足以下条件[^1]：

* **应用条件**：使用单位应具有完善的管理体系和较高的管理水平，建立健全应急预案并定期演练，管道运行良好且资料齐全完整，工艺操作稳定，生产装置采用数字集散控制系统（DCS）并有可靠的安全联锁保护系统。
* **实施要求**：承担 RBI 的检验机构需经特种设备安全监督管理部门核准取得相应资质；检验机构根据管道运行状况、损伤模式、风险可接受程度等进行风险评估，提出检验策略（包括检验时间、内容和方法），出具风险评估报告；使用单位据此制订检验计划并落实保障管道安全运行的各项措施。

管道安全状况等级根据定期检验结果综合评定，分为 1 级、2 级、3 级、4 级和 5 级，以其中项目等级最低者作为评定等级（TSG 31-2025 第 7.1.3 条、第 7.4 条）[^1]。

**金属管道定期检验周期：**[^1]

金属管道一般在投入使用后 **3 年内**进行首次定期检验，以后的检验周期由检验机构根据管道安全状况等级按下表确定：

| 安全状况等级 | 检验周期 | 备注 |
| :----------: | -------- | ---- |
| 1 级、2 级 | 一般不超过 6 年 | — |
| 3 级 | 一般 3 年至 6 年 | — |
| 4 级 | 监控使用，周期由检验机构确定 | 累计监控使用时间不超过 3 年 |
| 5 级 | 不得继续使用 | 应当对管道缺陷进行处理，否则不得继续使用 |

* 采用基于风险的检验（RBI）时，检验周期可采用以下方法确定[^1]：
  * 依据 RBI 结果可适当延长或者缩短检验周期，但最长不超过 **9 年**；
  * 以管道剩余寿命为依据时，检验周期最长不超过管道剩余寿命的 **1/2**，并且不得超过 **9 年**。
* 检验项目一般包括宏观检验、壁厚测定、表面缺陷检测、无损检测、理化检验、耐压试验等。

## 本项目定级、监管、定期检查说明

根据本项目动力设计说明，本项目工业管道系统定级及监管要求如下。

**关键结论**：本项目高压气体管道（高压氮气、高压压缩空气）公称直径均小于 50 mm（如高压氮气阀门 ≤ DN10），不满足《特种设备目录》及 TSG 31-2025 适用范围“公称直径 ≥ 50 mm”的条件[^1][^6]，虽设计压力达到 GC1 级划分条件，但**不属于特种设备监管范围**，无需办理使用登记、监督检验和按 TSG 31-2025 定期检验；设计、施工仍应按 GB/T 20801.1-2025 高压管道技术要求执行[^2]。

### 一、管道系统定级汇总

| 系统 | 介质 | 设计压力 | 工作压力 | 公称直径 | 定级 | 是否归属特种设备监管 | 定级、监管依据 |
| ---- | ---- | :------: | :------: | :------: | ---- | :------: | -------- |
| 高压氮气系统 | 高纯氮（无毒、不可燃、无腐蚀性气体） | **23.5 MPa** | 21 MPa | **< 50**（最大DN40） | GC1 | 否 | 设计压力 ≥ 10.0 MPa 满足 GC1 划分条件，但 DN < 50 mm 不在《特种设备目录》及 TSG 31-2025 适用范围 |
| 高压压缩空气系统 | 压缩空气 | **35 MPa** | — | **< 50**（最大DN40） | GC1 | 否 | 设计压力 ≥ 10.0 MPa 满足 GC1 划分条件，但 DN < 50 mm 不在《特种设备目录》及 TSG 31-2025 适用范围 |
| 低压压缩空气系统 | 压缩空气 | 1.0 MPa | 0.6~0.8 MPa | < 150（最大DN125） | GC3 | 否 | 公称直径 < 150 mm 且最高工作压力 < 1.6 MPa，不在《特种设备目录》及 TSG 31-2025 适用范围 |
| 低压氮气系统 | 氮气 | 1.0 MPa | 0.6~0.8 MPa | < 150（最大DN40） | GC3 | 否 | 公称直径 < 150 mm 且最高工作压力 < 1.6 MPa，不在《特种设备目录》及 TSG 31-2025 适用范围 |

### 二、监管要求

监管要求（设计签字、无损检测、监督检验、使用登记）仅适用于纳入《特种设备目录》监管范围的管道（DN ≥ 50 mm）。本项目高压气体管道 DN < 50 mm 不在监管范围，TSG 31-2025 / TSG D7006-2020 的特种设备监管要求对其不适用，但其**设计技术要求仍按 GB/T 20801.1-2025 GC1 级执行**[^1][^2]，具体对照如下：

| 项目 | 本项目高压管道（< DN50），不属特种设备监管范围 |
| -------- | ------------------------------------------ |
| 设计文件签字 | 不适用 TSG 签字要求；设计文件按 GB/T 20801.1-2025 GC1 级技术要求编制（材料等级表、应力计算书等） |
| 无损检测 | 不适用 TSG 抽检比例；焊接接头检测按 GB/T 20801.1-2025 GC1 级检查等级 Ⅰ 执行（目视、磁粉/渗透、射线/超声均 100%） |
| 监督检验 | 不适用特种设备监督检验；施工质量验收按 GB 50235-2010、GB 50184-2011 执行[^9][^10] |
| 使用登记 | 不适用特种设备使用登记；按企业设备管理制度建档管理 |

### 三、定期检查

TSG 31-2025 定期检验周期适用于纳入特种设备监管范围的管道。本项目高压气体管道（DN < 50 mm）不在特种设备监管范围，不适用该检验周期；建议使用单位参照 GB/T 20801.1-2025 及企业设备管理制度开展日常检查和维修保养[^1][^2]。监管范围内 GC2 级管道按下表执行：

| 检查项目 | 要求 |
| -------- | ---- |
| 首次定期检验 | 投入使用后 **3 年内**进行 |
| 检验周期 | 安全状况等级 1/2 级一般不超过 6 年；3 级一般 3~6 年；4 级监控使用且累计不超过 3 年；5 级不得继续使用 |
| 检验项目 | 宏观检验、壁厚测定、表面缺陷检测、无损检测、理化检验、耐压试验等 |

### 四、其他监管要求

* **耐压试验**：各系统管道安装完成后，压缩空气管道采用液压试验，试验压力为设计压力的 **1.5 倍**；高压氮气管道采用气压试验，试验压力为设计压力的 **1.15 倍**（动力设计说明及规范）[^9]。

| 监管事项 | 本项目适用情况 | 要求 | 依据 |
| -------- | -------------- | ---- | ---- |
| 安装告知 | 无 | 管道安装前，安装单位应向管道安装工程所在地的特种设备安全监管部门办理安装告知 | TSG 31-2025 4.1.2 |
| 材质复验（PMI） | 无 | 不适用特种设备监管要求；建议按 GB/T 20801 及设计文件对不锈钢管材进行材质核验 | TSG 31-2025 4.3.2.2 / GB/T 20801 |
| 高压管道专项要求 | 无 | 均低于 42 MPa，**不触发**高压管道专项要求（最高工作压力 ≥ 42 MPa 的管道统称为高压管道） | TSG 31-2025 注 1-1、2.4 |
| 管道组成件制造监检 | 无 | 不在制造监检范围内（制造监检覆盖埋弧焊钢管、聚乙烯管及元件组合装置中的燃气调压装置、减温减压装置、工厂化预制管段、流量计（壳体）） | TSG D7006-2020 1.2.1 |

| -------- | ---- | ------------- |
| TSG D0001-2009 压力管道安全技术监察规程—工业管道 | 作废 | 整合入 TSG 31-2025 |
| TSG D7005-2018 压力管道定期检验规则—工业管道 | 作废 | 整合入 TSG 31-2025 |

| TSG D7001-2005、TSG D7001-2013 压力管道元件制造监督检验规则 | 作废 | 整合入 TSG D7006-2020 |
