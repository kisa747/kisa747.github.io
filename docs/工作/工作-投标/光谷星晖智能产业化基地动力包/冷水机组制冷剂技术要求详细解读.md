# 冷水机组制冷剂技术要求详细解读

## 一、招标要求与判定框架

招标对冷水机组制冷剂的原始要求（来自 `23 64 15 离心式冷水机组.md`、`0809公用动力包定义文件.md`）：

> **满足 LEED 金奖认证环保制冷剂，且满足蒙特利尔协议 2030 年后不被淘汰的冷媒。**

该句实际包含**两条独立且都要满足**的考核维度，需分开判定，缺一不可：

| 维度                  | 核心命题                                   | 主要依据                                             |
| ------------------- | -------------------------------------- | ------------------------------------------------ |
| 要求①：蒙特利尔"2030 后不淘汰" | 冷媒在《蒙特利尔议定书》（基加利修正案）框架下到 2030 年不被淘汰/禁用 | 基加利修正案 + 国家受控清单                                  |
| 要求②：LEED 金奖环保制冷剂    | 冷媒满足 LEED 对制冷剂管理的考核要求（低 GWP）           | LEED v4.1 / v5 · Enhanced Refrigerant Management |

> ⚠️ 注意：**LEED 认证的是"建筑"，不是"制冷剂"**；不存在"某款制冷剂被 LEED 金奖认证"。真正考核制冷剂的是 LEED 的"Enhanced Refrigerant Management（强化制冷剂管理）"得分项。招标用语应从"制冷剂管理考核要求"角度理解。

---

## 二、要求①：蒙特利尔协议"2030 年后不被淘汰"解读

### 2.1 术语澄清

蒙特利尔议定书对制冷剂有两类完全不同的管制逻辑：

| 类别                                                                                                                                                 | 管制方式                 | 2030 处境                                      | 示例                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- | -------------------------------------------- | ------------------------------- |
| **ODS（CFC/HCFC）**                                                                                                                                  | **淘汰**（phase-out）    | **2030 年前后全面淘汰**（中国含氢氯氟烃 HCFCs 到 2030 年完全淘汰） | R22、R123（HCFC）、R11、R12（CFC）     |
| **HFC**（[基加利 Annex F 18 种](https://ozone.unep.org/treaties/montreal-protocol/amendments/kigali-amendment-2016-amendment-montreal-protocol-agreed)） | **削减配额**（phase-down） | 2024 冻结、逐年递减——**未禁用，但配额收紧**                  | R134a、R410a、R32、R125            |
| **HFO / 天然工质**                                                                                                                                     | 低 GWP，受扶持            | 基本不受削减约束，面向未来                                | R1234ze、R1233zd、R513A、R744(CO₂) |

> 依据（[生态环境部大气环境司答记者问](https://www.mee.gov.cn/ywdt/zbft/202408/t20240805_1083390.shtml)）：「随着最后一类 ODS 含氢氯氟烃（HCFCs）在 **2030 年完全淘汰**……」——这是唯一到 2030 年会被"淘汰"的制冷剂类别。**HFC（含 R134a）走的是"削减配额"，不是"淘汰"。**

### 2.2 基加利修正案时间表（中国 = A5 第一组）

中国属《蒙特利尔议定书》第五条款（A5）第一组，实际适用的是 **Article 5 第 8quare(a)** 这一经调整的时间表（生产与消费均须达标），依据为 [UNEP·基加利修正案官方文本](https://ozone.unep.org/treaties/montreal-protocol/amendments/kigali-amendment-2016-amendment-montreal-protocol-agreed)。

| 时间区间          | 相对基线（CO₂ 当量） | 削减幅度          |
| ------------- | ------------ | ------------- |
| **2024–2028** | **100%**     | **冻结**（不得超基线） |
| **2029–2034** | **90%**      | 削减 10%        |
| **2035–2039** | **70%**      | 削减 30%        |
| **2040–2044** | **50%**      | 削减 50%        |
| **2045 起**    | **20%**      | 削减 80%        |

- **基线** = 2020–2022 年 HFC 生产/使用均值 + **65% × HCFC 基线**，按 **CO₂ 当量**（用 Annex F 的 GWP）折算；中国生产基线 ≈18.53 亿 t CO₂e、使用基线 ≈9.05 亿 t CO₂e（[生态环境部《2024 年度氢氟碳化物配额总量设定与分配方案》](https://www.mee.gov.cn/ywdt/zbft/202408/t20240805_1083390.shtml)）。
- **口径要点**：管控的是 **CO₂ 当量总量**而非某个品种数量 → 高 GWP 冷媒（R134a GWP=1430）配额消耗快、优先承压；低 GWP（R1233zd/R1234ze）几乎不耗配额。
- 配套管控：2021-09-15 基加利对中国生效；2021-11-01 HFC 进出口许可证；2022-01-01 部分 HFC 新建/扩建受限；2024 起 18 种 HFC 配额管理。

**结论**：2030 年处于 **2029–2034 档（=90%，仅削减约 10%）**，故 R134a 等 HFC **在字面上"勉强满足"要求①**（未淘汰、仅配额收紧）；但到 **2045 年只剩 20%**，高 GWP 冷媒长周期内显著受挤压。

### 2.3 "2030 后不淘汰"的核心要求（判据清单 R1–R6）

| 编号  | 核心要求              | 判别标准                                           | R134a(1430) 符合？                                                                                                                         |
| --- | ----------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | 非 ODS（非 CFC/HCFC） | 必须是 HFC/HFO/天然工质；HCFC 到 2030 必淘汰               | ✅                                                                                                                                       |
| R2  | 属基加利受控但仅"削减"      | 未列入禁用/淘汰清单；是 Annex F 受控 HFC 但走削减路径             | ✅                                                                                                                                       |
| R3  | GWP 不过高、在主流削减承受范围 | GWP 越低越"未来无忧"；高 GWP HFC 区域禁令趋严                 | ⚠️（1430 偏高，[US EPA](https://www.epa.gov/ozone-layer-protection/recent-international-developments-under-montreal-protocol) 2024 起新装冷机禁用） |
| R4  | 满足区域/项目法规         | 满足项目所在地（GB 55015、GB 19577）及业主/LEED 低 GWP（≤750） | ❌（不满足 LEED）                                                                                                                             |
| R5  | 制造商产品线长期支持        | 冷机厂仍主力供货、未停产替代                                 | ⚠️（欧美新装冷机已转 R513A/R1233zd）                                                                                                              |
| R6  | 机房可行性（安全等级）       | A1 不可燃，或 A2L 且机房满足通风/防爆                        | ✅（A1）                                                                                                                                   |

> R134a 满足 R1/R2/R6，故字面够"2030 不淘汰"；但 R3/R4/R5 不达标 → 属"过渡性、被政策收紧"而非"省心可长期使用"。

## 三、要求②：LEED 金奖"环保制冷剂"解读

### 3.1 LEED 考核对象与层级

- LEED 认证**建筑**（Gold≈60–79 分），制冷剂考核属**能源与大气（EA）**类（[USGBC·Enhanced Refrigerant Management v4.1](https://www.usgbc.org/credits/new-construction-core-and-shell-schools-new-construction-data-centers-new-construction)），分**两层**：
  - **前置条件（必做，不占分）**——Fundamental Refrigerant Management；
  - **得分项（1 分）**——Enhanced Refrigerant Management。

### 3.2 前置条件：Fundamental Refrigerant Management（必做）

要求：**禁止使用 CFC**（R-11、R-12）；新建项目所有新设备不得含 CFC（[USGBC·Fundamental Refrigerant Management 前置条件](https://www.usgbc.org/node/2765073)）。
→ R134a 为 HFC，**ODP=0**，通过。但这只是"下限"，谈不上"环保"。

### 3.3 得分项：Enhanced Refrigerant Management（1 分）——真正的考核点

**Option 1（最直观）**：不使用制冷剂，或仅使用 **ODP=0 且 GWP < 50** 的制冷剂（[USGBC·Enhanced Refrigerant Management v4.1](https://www.usgbc.org/credits/new-construction-core-and-shell-schools-new-construction-data-centers-new-construction)）。

**Option 2（算式法）**：按制冷量加权的生命周期公式 `Σ(LCGWP + LCODP×10⁵) ≤ 100（IP 单位）/ ≤ 13（SI 单位）` 计算（[USGBC·Enhanced Refrigerant Management v4.1](https://www.usgbc.org/credits/new-construction-core-and-shell-schools-new-construction-data-centers-new-construction)）。通常仅极低 GWP + 小充注量系统可达标。

### 3.4 版本选型建议：LEED v5 vs v4.1（截至 2026-09，应选 v5）

**官方时间表（[USGBC，2026-05-28 更新](https://support.usgbc.org/hc/en-us/articles/25316160948755-LEED-v5)）**

| 版本                 | 状态                                                             | 注册截止              | 认证初审提交截止       |
| ------------------ | -------------------------------------------------------------- | ----------------- | -------------- |
| **LEED v5**        | ✅ 现行、当前版本（2025-04 开放注册）；2027-07-01 起为 BD+C / ID+C / O+M 唯一注册路径 | 持续开放（预计 ~2030 关闭） | 预计 ~2036 日落    |
| **LEED v4 / v4.1** | 🟡 过渡中，仍可注册                                                    | **2027-06-30**    | **2033-06-30** |

**建议：采用 LEED v5。** 理由：

1. **时间线契合**：本项目建设期 2026–2027、movein 2027-06、完工 2027-12，认证预计落在 2028–2033；v4.1 属"正在退场"的旧标，v5 已是现行且 2027-07-01 起强制。
2. **免被迫迁移**：若锁 v4.1，后期切 v5 时文件与表单须重做；直接按 v5 从一开始就锚定现行要求。
3. **制冷剂条款更友好**：v5 用加权平均 GWP ≤80%（1 分）/≤50%（2 分）（[USGBC·Enhanced Refrigerant Management v5](https://www.usgbc.org/credits/new-construction-core-and-shell/v5/eac7)）；v4.1 Option 1 为硬性 ODP=0 且 GWP<50。v5 更贴合"低 GWP 组合"的现实工程路径，也更容易拿到 2 分。
4. **版本周期**：LEED 已改为 5 年一版（v5 为 2025 版，v6 预计 ~2030 开放注册），选中 v5 即用足当前完整生命周期。

**制冷剂口径联动**

| 采用版本            | 制冷剂考核口径                          | 推荐冷媒                                                                                                                                                                                         |
| --------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LEED v5（推荐）** | 全系统加权平均 GWP ≤80% / ≤50%          | **R513A（直替 R134a）** 适合；**R1233zd(E)/R1234ze(E)** 最稳；R134a 仍不推荐（[USGBC·v5](https://www.usgbc.org/credits/new-construction-core-and-shell/v5/eac7)）                                            |
| LEED v4.1       | Option 1 硬性 ODP=0 且 **GWP < 50** | 仅 **R1233zd(E)（A1）/R1234ze(E)（A2L）** 达标；R513A、R134a 均不达标（[USGBC·v4.1](https://www.usgbc.org/credits/new-construction-core-and-shell-schools-new-construction-data-centers-new-construction)） |

**落地要点**：① 招标"LEED 金奖"按 **LEED v5（BD+C：New Construction）** 申报，注册走 Arc 平台；② 制冷剂按 v5 口径——**全系统加权平均 GWP ≤50%（冲 2 分）**，可接受 R513A + 低 GWP 混配，推荐标配 R1233zd(E)/R1234ze(E)；③ 若业主/顾问执意沿用 v4.1，则须按 **GWP < 50** 卡、切不可用 R134a/R513A，且须 **2027-06-30 前注册**，避免错过窗口。

## 四、常见冷媒符合性对照（综合要求① + ②）

| 冷媒             | GWP  | ODP | 可燃性 | 基加利"2030 不淘汰" | LEED v4.1 得分项   | LEED v5      | 总体结论               |
| -------------- | ---- | --- | --- | ------------- | --------------- | ------------ | ------------------ |
| **R134a**      | 1430 | 0   | A1  | ✅（字面，削减非淘汰）   | ❌（GWP≫50；算式难达标） | ❌（拉高加权平均）    | **不满足**（过渡性）       |
| **R513A**      | ~573 | 0   | A1  | ✅             | ❌（GWP>50）       | ⚠️ 加权平均达标可通过 | 满足"环保"但非严格 v4.1 达标 |
| **R1234ze(E)** | ~6   | 0   | A2L | ✅             | ✅               | ✅            | **符合**（需机房 A2L 通风） |
| **R1233zd(E)** | ~1   | 0   | A1  | ✅             | ✅               | ✅            | **符合**（首选，A1）      |
| R744(CO₂)      | 1    | 0   | A1  | ✅             | ✅               | ✅            | 符合（天然工质）           |

## 五、结论与推荐选型

1. **本项推荐（按 LEED v5 口径）**：制冷剂以"**全系统加权平均 GWP ≤50%（冲 2 分）**"考核；首选 **R1233zd(E)（A1，GWP≈1）** 或 **R1234ze(E)（GWP≈6，需机房 A2L 可行）**，或 **R513A + 低 GWP 混配**拉低加权平均达标——满足"环保 + LEED v5 + 2030 后不淘汰"。
2. **若业主/顾问沿用 LEED v4.1**：须按硬性 **ODP=0 且 GWP < 50** 卡，仅 **R1233zd(E)/R1234ze(E)** 达标，且须 **2027-06-30 前注册**；R513A、R134a 均不可用。
3. **R134a 明确排除**：仅满足"禁 CFC"下限与"2030 字面不淘汰"，达不到 LEED 环保制冷剂考核要求。
4. **投标澄清必须锁定**：要求厂家提供同型号产品——制冷剂 GWP/ODP 值、ASHRAE 安全等级、整机加权平均 GWP 计算书、是否满足 LEED v5"强化制冷剂管理"条款，并明确"环保冷媒"具体牌号。
