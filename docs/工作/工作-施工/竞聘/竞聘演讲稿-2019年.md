# 2019年演讲

尊敬的各位领导，我是梅京奎，来自郑州经理部河南科技馆项目。我是第一批的责任工程师，主要经历了郑州新郑国际机场、郑州港区棚户区二标、河南科技馆项目。今天我讲三条经验总结，以及新的机遇与挑战。
第一，管理作用。作为责任工程师，是公司成本管控、精益建造、科技创新等理念的践行者，是讲公司各种理念传达到施工队伍的第一人，否则纵使有再多的新理念，如果不能得到有效的执行，也只会仅停留在纸面上。
第二，明确责任，团队协作。对内的任务即是劳务队伍的管理者，也是各种技术方案的编写与实施者。对外是与设计院、监理沟通的桥梁。因此一个扁平化高效的团队，实现一加一大于二的效果。
第三，做好技术带头人的模范作用，科技创新。
