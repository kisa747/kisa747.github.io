# 2023年演讲

尊敬的各位领导，我是梅京奎，来自徐州金弗二期项目。今年我经历了2个项目，上半年在洛阳光电产业园项目，10月之后调至徐州金弗二期项目。两个项目对我来说都很有挑战，洛阳光电产业园第一次负责暖通专业并兼职商务工作；徐州金弗二期项目第一次做包含了冰水站、工艺气站、导热油锅炉房的，面积超过1万平方米的大型能源中心机房。我也就我经历的项目，谈一下我对责任工程师的理解和认识。

一、夯实专业知识基础，提高业务水平能力

作为责任工程师，要具备扎实的专业基础，过硬的专业能力。只有这样，在施工时才能编制优秀的项目施工方案、技术交底，做到施工有依据，结算有根据。施工过程中做好技术工作，也是为商务工作提供坚定有力的技术支撑。

时代在进步，科技在发展，我们也在遇到新的问题，这就要求我们不断学习新知识，不断提高自身的业务水平能力，适应并掌握公司的各项流程。

除了具备专业方面的知识外，还应懂得与整个团队沟通，通过个人为整个团队带来正能量。注重强化传帮带工作，在工作中为新员工做好带头作用。

二、重策划
现在的大型项目，普遍施工难度高、工期紧，而且图纸设计经常出现大的变动。

所以要想保证大上阶段材料能跟的上，新进场管理人员能快速熟悉现场、熟悉图纸，必须要在前期做好物资策划，技术策划，商务策划。

另外在物资招标时就要考虑后期施工中可能会遇到的问题，后面结算容易产生纠纷的问题。招标时不要嫌麻烦，多跟厂家沟通参数，有必要时重新深化设计，对于施工中容易丢失、容易增减、容易有争议的部分，招标时应该单独考虑。

三、重BIM设计

随着技术的进步，越来越多项目都在使用BIM，但是很多BIM设计人员其实对现场施工并不熟悉，这就需要我们现场一线管理人员参与到BIM深化设计当中。

Bim深化不仅仅是要求美观就可以了，更多是要求满足功能，便于施工，便于维护。除了基本的小管让大管，有压让无压，还要综合各专业，考虑排布的层次，检修、维修空间，功能分层等。

bim 综合排布考验的是一名管理人员对机电全专业的综合理解，需要工长熟悉了解各个专业的特点，才能做好bim综合排布。

接下来的工作计划

总结金弗项目大型工艺机房的施工经验。以后类似的项目，可以提前规避风险，推广优秀做法。

很多总承包项目的经验，在 EPC 项目都失效了，指挥部甲方更多是将我们施工单位和设计院作为一个联合体考虑。所以很多变更，我们不仅需要设计变更，也需要指挥部的需求变化文件，包括会议纪要、工作联系函等。
