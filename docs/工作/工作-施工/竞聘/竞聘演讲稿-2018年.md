# 2018年竞聘演讲

尊敬的各位领导、各位同事，大家好！我是梅京奎，来自郑州经理部航空港棚户区二标，今天我要竞聘的岗位是项目副经理。
    我是2014年底加入公司，在新郑机场、永和龙子湖中央广场项目任暖通工长，现在棚户区二标任水暖责任工程师。每一次在这里，感受都不一样。也借这个平台呢，重新审视了自己过去的工作，未来的规划。也借这个平台提高自己的站位高度。
    对于我现在的岗位和我要竞聘的岗位，我想从以下几个方面阐述和说明我的一点认识和想法。
     第一，制定一个清晰完整可行的计划方案，并进行追踪。工欲善其事必先利其器，而而一个切实可行得计划就是手中的利器，追踪计划实施就是善用这把利器。通过计划和方案，过程中很多的问题就可以提前发现，提前判断，有很多东西在过程不是要求立即完成，如果没有一个宏观的计划，最后就会拖拖拉拉直至抛至脑后。
     第二、专业能力和再学习能力。我常在思考一个问题，是什么阻碍了不断地再学习，是自认为已经不学习了，还是太忙没有时间？而这些都不是借口，一个优秀的副经理必定是有一定的专业技术水平，到更重要的是换个站位总结和提炼这些知识，不能固步自封，继续学习管理和组织技能。
     第三、整合能力。通过整合不同人员的能力、整合内部和外部的资源，扬长避短，提升团队的整体水平，给团队注入新鲜血液，打造一个强健、没有短板的团队。我们有一整套完整的公司规章制度，但到项目上具体到一个工长，如何去理解、去准确执行公司的制度，却是一件很难的事情。通过整合不同员工的经验和认识，可以从一个全新的角度，来重新认识和理解公司制度的前因和后果，也就更好的执行制度。
   最后感谢领导让我有机会思考，并分享出来。谢谢，我的演讲结束了。
